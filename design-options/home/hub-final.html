Three ways to read how an AI system is built.

Every pattern lives in a Layer of the stack. Every Discipline cuts across all of them. Every Build is a real system assembled from patterns drawn across the layers. Start anywhere, then drill in.

Layers stack vertically · Disciplines run as rails across them · Builds draw from several layers at once
Disciplines → all Layers. Evaluation, safety, privacy, observability and cost are not a layer; they are rails that touch every layer.
Builds ← several Layers. A Build like Document Q&A wires together retrieval, control, composition and serving patterns into one product.
