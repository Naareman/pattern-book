Shape its output

How you control the form the answer comes back in.

Lock the format

Want the answer in a fixed shape? → Structured Output↗
Want it to fill exact fields? → Schema Enforcement↗
Want it to only produce valid output? → Constrained Decoding↗
Want to repair the format afterward? → Format Coercion↗

Control how it writes

Want it to stop at the right point? → Stop Sequences↗
Want answers more or less random? → Temperature & Sampling↗
Want to nudge it toward or away from certain words? → Logit Biasing↗

As it generates

Want it to keep the best few options as it writes? → Beam Search↗
Want to check it while it streams? → Streaming with Validation↗
