Automation and workflow execution

The AI runs a real procedure end to end. The output is the work itself, done in the world.

01What is it?

A multi-step job, actually run.

The input is a goal. The output is a series of real actions taken: forms filled, emails sent, records updated, browsers driven, files moved. Each step touches outside systems and leaves a trace.

03Where it fits

How it sits next to other shapes.

Sits next to
Decision. A decision picks what should happen. Automation goes and does it, often with several tool calls and side effects along the way.
Highest cost
Generation can be reviewed before sending. Automation changes the world as it runs. A mistake is already done by the time it shows up.
04When it matters

When to reach for it.

  • A procedure is well defined, runs often, and each step has a clear tool to call.
  • Speed and consistency beat human-in-the-loop review for the routine cases.
  • Approval gates and undo paths exist for the rare cases that should pause for a human.
