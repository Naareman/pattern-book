Conversational Assistant

A chat interface that remembers what you said earlier and answers helpfully, turn by turn.

01The Idea

What is it?

A Conversational Assistant is the simplest AI product that still feels genuinely intelligent: you type, it replies, and it clearly remembers what you discussed earlier. Under the hood, the whole conversation history is packed into a single prompt (the text you send the AI) each turn, so the model can read everything said so far. The "memory" is not magic; it is the growing transcript the system passes back in with each new message.

03Patterns It Uses

The pieces inside.

User experience
Conversational Surface + Streaming
The chat window itself, with words appearing as the model writes them so the wait feels shorter.
Stateful Memory
Conversation Memory (Rolling Window)
Every message is kept in a running transcript and re-sent each turn, with older turns trimmed or summarized to fit.
Single-call control
Prompt Shaping + Output Shaping
A fixed instruction block sets tone and rules, and output limits keep replies concise, all inside one model call.
⚠
Safety Note: Refusal calibration
It must decline harmful requests without being so cautious it becomes unhelpful. The instruction block is the main lever.
04Sequencing

How a turn flows.

1
User Types
The new message arrives. The system appends it to the conversation history kept in memory.
2
Prompt Assembled
The full transcript is packed into a prompt (the text you send the AI) alongside the system-level instructions. If the conversation is very long, older turns may be summarised first to save space.
3
Model Called
One call to the model (the AI model, also called the LLM). The model reads the whole transcript and generates a reply token by token.
4
Reply Streams
Tokens are forwarded to the screen as they arrive. The user sees words appearing before the full reply is done.
5
Memory Updated
The completed reply is appended to the transcript so the next turn can reference it. The loop restarts at step 1.
05Tradeoffs

The price you pay.

LowHigh
Cost Per Turn

Complexity
Memory Depth
Cost and wait time grow with conversation length: every turn re-sends the full transcript, so a 30-turn chat costs more than a 3-turn one. The fix (summarising old turns) saves tokens but risks forgetting specific details. That is the central tradeoff of rolling-window memory.
