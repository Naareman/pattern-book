Multimodal cost attribution

A single dollar figure for a multimodal app hides where the money goes. Split the bill by input shape so you can see which inputs drive the spend.

01What Is It?

Tag every token by where it came from.

Multimodal cost attribution tags each token by its input type (text, image tile, audio second) and rolls up totals by shape, so a bill spike points to the specific modality that grew rather than one unexplained number.

03Where It Fits

How it sits next to nearby ideas.

A flavour of
The general cost-attribution discipline. The shape is the same: tag, roll up, look at the slice, act on the largest slice.
Pairs with
Latency budgets. The same traces that record tokens per input type record time per input type, so you only need one logging pass to feed both views.
04When It Matters

When to think about it.

  • The monthly bill jumped and the single total figure does not tell you which feature caused it.
  • You charge users by the call but pay vendors by the token, so per-shape costs decide your margin.
  • A free tier lets users send images or audio, and you need a cap before one heavy user drains the budget.
