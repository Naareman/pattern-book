Single-Call Control

How do you get the best answer out of a single message to the AI?

Ask it well

Copy a style you show it Few-Shot↗ Just ask, no examples Zero-Shot↗
Give it a role or voice Role / Persona
Tell it what to avoid Negative Prompting
Reuse a fill-in-the-blank prompt Prompt Templates

Guide its thinking

Get a hard problem right Chain-of-Thought↗
Make it plan before answering Plan-and-Solve
Start from the big picture Step-Back
Break it into small steps Least-to-Most
Get a more reliable answer Self-Consistency↗

Shape the output

Get the answer in a fixed format Structured Output↗
Make it stop at the right point Stop Sequences
Make it more or less creative Temperature & Sampling

Make it check itself

Have it review and fix its answer Self-Reflection↗
Have it double-check its facts Chain-of-Verification
Have it ask itself sub-questions Self-Ask
Have it argue both sides first Debate-Then-Decide

Advanced controls

Delimiters mark where each part starts

Meta-Prompting let it write the prompt

Example Selection pick the best examples

Example Ordering order examples on purpose

Context Packing fit the key info in

Lost-in-the-Middle Mitigation put key facts at the edges

Prompt Compression shrink the prompt to save cost

Analogical Prompting reason from a similar case

Tree-of-Thoughts explore several paths, pick best

Skeleton-of-Thought outline first, fill in parallel

Schema Enforcement force valid fields

Constrained Decoding only allow valid tokens

Streaming with Validation check it as it streams

Format Coercion repair the format after

Logit Biasing nudge specific words

Beam Search keep the best few continuations

All of these happen inside one message to the AI.
