Layer · L4

Single-Call Control

Every knob you can turn inside one message to the AI, before and after it thinks.

Nothing here needs a second call. A second call is L5; a second model is L2.

Inside This Layer

Input Shape

Zero-Shot Framing ↗ Describe what you want, no examples. → Few-Shot Framing ↗ Give it a few examples to copy. →
Role / Persona Give the AI an identity to set tone.
Delimiters Markers that keep instructions and data apart.
Negative Prompting Tell it what not to do or include.
Meta-Prompting Ask the AI to write the prompt itself.
Prompt Templates Reusable skeletons with fill-in placeholders.
Example Selection Pick which examples to include per query.
Example Ordering Order examples deliberately; position shifts attention.
Context Packing Fit the most useful info in the budget.
Lost-in-the-Middle Mitigation Put key content at the edges, not the middle.
Prompt Compression Shrink the prompt to cut cost and latency.

Cognitive Strategy

In-Prompt
Step-Back Answer a broader version first, then the specific.
Least-to-Most Break into sub-problems, solve easiest first.
Plan-and-Solve Write a plan first, then execute each step.
Analogical Prompting Recall a relevant analogy before answering.
Chain-of-Thought ↗ Ask it to think step by step. →
In-Decoding
Tree-of-Thoughts Explore many reasoning paths like a search tree.
Skeleton-of-Thought Outline first, then fill sections in parallel.
Self-Consistency as Search ↗ Sample many paths, take the most common. →

Self-Verification

Self-Reflection ↗ Review and revise its answer in the same call. →
Chain-of-Verification Ask yes/no checks about its own answer.
Self-Ask Answer its own follow-up sub-questions first.
Single-Model Debate-Then-Decide Argue both sides, then decide, in one call.

Output Shape & Decoding

Structured Output ↗ Tell it the exact shape to return. →
Schema Enforcement Supply a formal schema of required fields.
Constrained Decoding Limit generation to a valid grammar.
Streaming with Validation Check output as it streams, not after.
Format Coercion Fix raw output to match the wanted format.
Temperature & Sampling Low is focused; high is varied and creative.
Logit Biasing Boost or suppress specific tokens before sampling.
Stop Sequences Strings that halt generation on contact.
Beam Search Keep top candidate sequences, pick the best.
Filing rule: if it happens inside one call to one model, it belongs here. A second call is L5. A second model is L2.
