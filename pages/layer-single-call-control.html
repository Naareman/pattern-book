Layer · L4

Single-Call Control

How do you get the best answer out of a single message to the AI?

Inside this layer

Few-Shot↗ give it examples to copy Zero-Shot↗ just ask, no examples
Role / Persona tell it who to be
Delimiters mark where each part starts
Negative Prompting say what to avoid
Meta-Prompting let it write the prompt
Prompt Templates reusable fill-in-the-blank prompts
Example Selection pick the most relevant examples
Example Ordering order examples on purpose
Context Packing fit the key info in
Lost-in-the-Middle Mitigation put key facts at the edges
Prompt Compression shrink the prompt to save cost

Step-Back answer a simpler version first
Least-to-Most solve the easy parts first
Plan-and-Solve plan, then do each step
Analogical Prompting reason from a similar case
Chain-of-Thought↗ think step by step
Tree-of-Thoughts explore several paths, pick best
Skeleton-of-Thought outline first, fill in parallel
Self-Consistency↗ answer a few times, vote

Self-Reflection↗ review and fix its answer
Chain-of-Verification draft check questions, answer them
Self-Ask ask itself sub-questions first
Debate-Then-Decide argue both sides, then choose

Structured Output↗ return a fixed shape
Schema Enforcement force valid fields
Constrained Decoding only allow valid tokens
Streaming with Validation check it as it streams
Format Coercion repair the format after
Temperature & Sampling dial randomness up or down
Logit Biasing nudge specific words
Stop Sequences tell it where to stop
Beam Search keep the best few continuations

All of this happens inside one model call. A second call is L5; a second model is L2.
