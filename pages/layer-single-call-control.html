Layer 6

Single-call control

Everything you can shape inside a single call to the model: how you write the prompt, how you make it reason, and how you constrain the output. No extra calls, no tools, no memory: just getting the most out of one request.

Shaping the input
Few-ShotTeach the format by showing a few examples. → Zero-shot & instructionsJust describe the task, no examples. →
Making it reason
Chain-of-ThoughtMake the model show its steps before answering. → Self-ConsistencySample several reasoning paths, take the majority. →
Shaping the output
Structured outputForce valid, parseable output (e.g. JSON to a schema). →
Checking itself
ReflectionThe model critiques and revises its own answer. →
