Browsing Agent

Navigates real websites to find an answer or complete a task, deciding where to go next after each page it reads.

01The Idea

What is it?

A Browsing Agent drives a real web browser toward a goal, looping through read, click, and type until it is done.

Read Only
Loading a URL, reading page text, scraping a table. Nothing changes if you do it twice.
Stateless Retrieval
Side-Effectful
Clicking a button, submitting a form, adding to a cart. Doing it twice may book twice.
Orchestration & agents
Orchestration & agents Stateless Retrieval Single-call control
