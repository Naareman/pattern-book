Hide personal details before the AI sees them

Strip names, emails, phone numbers, and IDs out of a request or a document before any of it reaches the model.

01What is it?

What is it?

A cleaning step that runs in front of the model at request time. It scans whatever you are about to send (a chat message, a support ticket, an uploaded file) and replaces personal details with a tag like [NAME] or [EMAIL]. The model sees the scrubbed version. The tags can be swapped back in the final answer if the user expects to see their own name. The point is simple: the model gets the meaning, the personal details stay with you.

03Where it fits

How it relates to nearby ideas.

When it happens: at the door of every model call. The user's words come in, the scrubber rewrites them, and the rewritten version is what gets sent.
Sits next to: the same cleaning idea is also done on training data and search indexes, but that is a separate offline pass on a stored dataset. This page is about the live request: the message a person types right now.
Quick test: does it act on a live message a user is sending? That is the runtime version. Does it run once over a whole stored dataset before any model uses it? That is the data-prep version, filed under data and artifact lifecycle.
04When it matters

When to reach for it.

  • You send user input to a model run by another company, where you would rather their logs hold tags than real names.
  • Your users paste in tickets, emails, or screenshots that often carry someone else's personal details.
  • You operate under rules like GDPR or HIPAA that ask you to limit how far personal data travels.
