Supervisor / Worker

One persistent supervisor agent routes a task to a small team of specialist workers, each with a fixed role, and stitches their outputs into a result.

Default in 2026One persistent supervisor and N specialists with stable identity. Build it with LangGraph supervisor or CrewAI hierarchical. Use when the workers have permanent specialization. NOT Planner-Executor: the workers persist across the task instead of being spun up per step.
01The Idea

What is it?

A Supervisor / Worker system is one boss agent with a memory of the whole task and a small bench of specialist workers (Planner, Coder, Reviewer). The supervisor decides who works next, hands them a scoped sub-task, reads what comes back, and updates its plan.

Named workers with stable roles make traces easy to read. The supervisor's extra round-trips are the cost: every worker hand-off is a model call, and you pay for them sequentially.
05Patterns It Uses

What's underneath.

Hierarchical planning: supervisor decides which worker runs next, in what order Agent identity: workers have persistent named roles (Planner, Coder, Reviewer) Router / dispatcher: each round, the supervisor routes the next sub-task to the right worker Shared workspace: the supervisor's state is the workspace every worker reads and writes through
06When To Use

Pick this over the look-alikes.

Pick Supervisor / Worker over
Planner-Executor
Supervisor / Worker has persistent specialized workers across the task. Planner-Executor spins up stateless steps each round. Use Supervisor when "Coder" is a real role with continuity, not a one-off function call.
Pick Supervisor / Worker over
Multi-Agent Research Team
Both have a lead. The Research Team's workers are interchangeable researchers, all doing the same kind of job in parallel. Supervisor's workers are different specialists: a Planner and a Coder are not swappable.
Pick Supervisor / Worker over
Flat Swarm
A Swarm has peers passing work to each other with no boss. Supervisor has clear authority: one agent decides who runs and merges the result. Use Supervisor for production. Use Swarm for research.
