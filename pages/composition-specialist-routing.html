Specialist routing

Send each question to the model that is best at that topic. Code questions go to the code model. Legal questions go to the legal model.

01What is it?

Right question, right expert.

A router classifies the question and forwards it to the one specialist model tuned for that topic, so only the right expert runs.

03Where it fits

How it sits with nearby ideas.

Compare to
Cascading routes by difficulty (cheap then expensive). Specialist routing routes by topic. You can stack them: pick the topic first, then cascade within it.
Pairs with
The router itself is usually a small classifier or a cheap model. It only needs to read the question, not answer it.
04When it matters

When to reach for it.

  • Your questions span clear topic buckets (code, legal, support, sales).
  • A general-purpose model gives flat answers in some areas and you have a model that does better there.
  • You want to run only one specialist per request so cost stays close to a single call.
