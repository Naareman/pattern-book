Evaluation

Checking that the AI is actually right, not just sounding certain.

01The Idea

What is it?

An AI can say the wrong thing in a very confident voice. Evaluation is the practice of testing it on questions where you already know the correct answer, then counting how often it gets them right. Without it, you are trusting the AI's tone instead of its accuracy.

03How We Measure

Four ways to catch a wrong answer.

Real evaluation combines several methods. Each covers something the others miss.

  • A
    Test set with known answers
    A fixed set of questions where the right answer is already written down. Run the AI through them, count how many it gets right. This is the baseline.
  • B
    Scoring functions
    Code that checks answers automatically: exact match, substring match, or a numeric score like BLEU for translation. Fast, cheap, consistent.
  • C
    Human review
    A person reads a sample of answers and rates them. Catches subtle errors that code misses, like a technically correct but misleading phrasing. Slow and expensive, so used on a sample, not everything.
  • D
    LLM-as-judge
    A second AI reads the answer and rates it against the known-correct answer. Scales better than human review and catches more nuance than code. It can still be fooled by confident-sounding errors, so it works best alongside a test set.
