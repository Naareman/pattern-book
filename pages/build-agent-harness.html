Agent Harness

A brain, a pair of hands, and a session. The shape every long-running agent ends up converging on.

Default in 2026 Anthropic Claude Code as reference. Brain = Claude. Hands = sandboxed bash + file tools + MCP servers. Session = persistent context + virtual filesystem. Add Skills (SKILL.md) for domain workflows.
01The Idea

What is it?

An Agent Harness splits the agent into three jobs: one model that thinks, a fixed set of tools that act, and a session that remembers. The harness is the box that keeps them coordinated across many steps.

02See it Work

Tap each piece.

Every harness is the same three jobs. Tap to see what lives where, using Claude Code as the reference shape.

Brain
The model and its plan
A single strong LLM does all the thinking. It reads the task, decides which tool to call next, and updates its plan after each result. No sub-team of models. One brain stays in charge for the whole session.
ModelClaude (Sonnet by default, Opus for hard turns)
DecidesWhich tool to call, with what arguments, when to stop
PlansWrites a todo list, ticks items off as it works
Why one model? Switching models mid-session breaks the plan. Keep one brain end-to-end; pick the model up front.

04Tradeoffs

The price you pay.

lowhigh
Cost per task
Latency to finish
Autonomy granted
Setup complexity
Blast radius if it errs
A harness is the most powerful shape and the most expensive one. Sandbox the hands, log every tool call, and put a hard turn limit on the loop. Without those three, it will spend money and break things in your name.

06When to Use It

Or pick something simpler.

Pick harness over Tool-using Agent Loop
When the task needs a persistent session across many steps, sub-agents for parallel work, and reusable skills. The plain agent loop fits a single bounded task; the harness fits an open-ended job.
Pick harness over Deep Research Agent
When the work is engineering, not research. Deep research produces a written report from sources. A harness produces edits, builds, and side effects in a real system. Different output, different shape.
