Analogical Prompting

Ask the model to generate its own examples of similar problems, then reason from those examples to solve yours.

01What It Is

Self-generated examples, then the answer.

Analogical Prompting instructs the model to surface its own similar problems with known solutions from training, then reason by analogy from those self-generated examples to solve yours.

02An Example

A coding problem solved by analogy.

Self-generated analogy
Reversing a string
The model recalls: walk from both ends toward the center, swap characters at each position until the pointers meet. Time: O(n), Space: O(1).
Target problem
Reversing a linked list
The same two-pointer swap logic applies. Use prev / curr / next pointers, redirect each link, advance. Time: O(n), Space: O(1).
Prompt instruction: "Before solving this problem, recall a similar problem and its solution. Then apply the same reasoning here."
03Where It Fits

Where it fits.

Home
A way of steering how the model reasons. It recalls a similar example and reasons from it, all inside one call to one model.
Neighbor
Few-Shot prompting also uses examples, but you write them. Analogical Prompting lets the model come up with its own, which is the key difference.
In short: the model writes its own examples as text in its reply. There is no separate search step or outside example store, so it stays in one call to one model.
04When It Matters

When to reach for it.

  • You want the lift of worked examples but cannot hand-write them for every kind of problem.
  • Your tasks vary so much that a fixed set of examples would miss most of them.
  • Best on math and coding, where matching the shape of the problem matters more than matching the words.
