Coding Agent

A helper that reads, writes, and fixes code for you. It loops until the tests go green.

01The Idea

What is it?

A Coding Agent is an AI that can read your files, edit code, and run tests, all on its own. You give it a task. It makes a plan, edits the right file, runs the code to see what happens, checks what broke, and fixes it. It keeps looping until everything passes. You watch. It works.

02See it Work

Watch the loop.

You give the agent a task. It plans, edits, runs, sees what fails, and fixes. Press Play to watch one full loop.

Task "Add a function that sums a list of numbers, and make its test pass."

Read math_utils.py and test_math_utils.py to understand what is missing. The test calls sum_list(), but that function does not exist yet.
Edit
Write the missing function into math_utils.py:
# math_utils.py
+ def sum_list(numbers):
+ return sum(numbers)
Run
Run the test suite and read the output.
Check & fix
Done
03A Real Example

What it looks like in practice.

1
You tell GitHub Copilot Workspace: "Refactor the login handler to use the new auth library." No more instructions needed.
2
The agent reads the current login code, finds every place that calls the old auth API, and writes a plan listing each file it will touch.
3
It edits each file, then runs the existing tests. Two fail. It reads the error messages, patches the two calls it missed, and runs again.
4
All tests pass. It opens a pull request with a description of every change it made. You review and merge.
04Tradeoffs

The cost of autonomy.

Risk of mistakes
The more autonomy you give it, the more LLM calls it makes per task. Good tests are essential: the agent uses them as its signal for "done." Without tests, it can loop forever or stop too soon.
