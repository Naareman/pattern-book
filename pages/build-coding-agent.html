Coding Agent

A helper that reads, writes, and fixes code for you. It loops until the tests go green.

01The Idea

What is it?

A Coding Agent is an AI that reads your files, edits the code, runs the tests, and keeps fixing what fails until everything passes.

Orchestration & agents Single-call control
02See it Work

Watch the loop.

You give the agent a task. It plans, edits, runs, sees what fails, and fixes. Press Play to watch one full loop.

Task "Add a function that sums a list of numbers, and make its test pass."
Iteration 1
Plan
Read math_utils.py and test_math_utils.py to understand what is missing. The test calls sum_list(), but that function does not exist yet.
Edit
Write the missing function into math_utils.py:
# math_utils.py
+ def sum_list(numbers):
+ return sum(numbers)
Run
Run the test suite and read the output.
Check & fix
Done

The price you pay.

Risk of mistakes
The more autonomy you give it, the more LLM calls it makes per task. Good tests are essential: the agent uses them as its signal for "done." Without tests, it can loop forever or stop too soon.
