Stateful Memory · What it remembers

Long-term user memory

Steady facts about you that stay true across chats: who you are, what you like, how you want answers.

01What it is

A small card the model keeps about you.

A user profile is a short, slow-changing record of stable facts you have shared with the system, loaded at the start of every chat so the model does not ask you the same things repeatedly.

02An example

Tap a row to see where it shows up.

Profile for user_nareman /memory/profile.json
Greets you by name. Next time you open a new chat, the first reply already says "Hi Nareman" without you saying it again.
03Where it fits

How it sits next to nearby ideas.

Sits next to
The running chat history. The chat is just this conversation. The profile is the slow-changing facts that carry across all your chats.
Not the same as
Specific past events ("you booked a flight to Rome last Tuesday"). Events are time-stamped moments. The profile is general traits.
04When it matters

When to reach for it.

  • You are tired of repeating the same setup ("I am a teacher", "reply in Arabic", "no shellfish") at the start of every chat.
  • You want the model to keep using your name, your tone, your defaults without being told.
  • You need a clear, editable list of what the system thinks it knows about you (so you can correct it).
