Versioning and lineage

Saving each version of a dataset and the chain of steps that produced it, so any result can be traced back.

01The idea

What is it?

Versioning saves a tagged snapshot of the dataset each time it changes; lineage is the breadcrumb trail recording which source each row came from and which processing steps it passed through.

03Where it fits

Where it sits in the flow.

Versioning and lineage are not a separate step. They run alongside every other step (collection, cleaning, labeling, training) recording who did what and when, so any later question can be answered without guessing.
04When it matters

When to care about it.

  • Something broke in production and you need to know which dataset version caused it.
  • A regulator or a customer asks where a particular answer came from.
  • More than one team trains models from the same data and needs a shared, dated reference.
