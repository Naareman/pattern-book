Application Patterns

Every AI feature is defined by what it does to its input. This layer names the six relationships between input and output that cover all application tasks.

01The Idea

Six jobs, one model.

One model, six jobs. What changes across AI features is not the model but the relationship between input and output.

03A Real Example

Where each one lives.

Customer support chatbot
Retrieval & Q&A
A user asks "where is my order?" The app finds and returns the answer from live order data.
News reader
Transformation
Turn a 1,200-word article into a 3-sentence brief. Same meaning, different form.
Legal contract tool
Extraction & Classification
Pull every date, party name, and payment amount out of a 40-page PDF and label each clause type.
Marketing tool
Generation
Write three ad variants from a product brief. The output did not exist in the input.
Product recommender
Decision & Recommendation
Score and rank ten products for this shopper, then surface the top three.
HR onboarding bot
Automation & Workflow Execution
Create the account, send the welcome email, and assign the training queue without a human in the loop.

05Inside This Layer

The six categories of L6.

Axis: the relationship between input and output.
Retrieval & Q&A
Finds and surfaces content that already exists.
Transformation
Same meaning, different language, length, or style.
Extraction & Classification
Pulls structured facts or labels from the source.
Generation
Produces content that did not exist in the input.
Decision & Recommendation
Picks, ranks, or scores options from a defined set.
Automation & Workflow Execution
Takes real-world actions across multiple steps.

Filing rule: Ask what transformation it performs on the input to make the output; file under the primary purpose. When a task spans multiple categories, cross-reference the secondary ones.
