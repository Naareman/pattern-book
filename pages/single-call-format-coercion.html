Format Coercion

Repair the format of a model's response after it arrives, using code rather than a second model call.

01What It Is

Fix it in code, not in the prompt.

Format coercion is a post-processing step that runs after the model responds and before the output is consumed. Instead of relying entirely on the model to produce the right format, a deterministic code layer cleans up common deviations: stripping markdown fences from a response asked for plain text, extracting a JSON object buried in prose, normalizing date strings, or trimming whitespace. It is the pragmatic complement to schema enforcement: you ask the model nicely, then fix what it gets slightly wrong. Coercion is not re-generation; it operates on the existing string without calling the model again.

02An Example

Three common fixes.

Model returned JSON wrapped in markdown
!
Raw model output
```json { "city": "Geneva", "year": "2024" } ```
The model wrapped valid JSON in a markdown fence the caller didn't ask for.
→
Coercion: strip fences + cast types
text = re.sub(r"^```\w*\n|```$", "", text, flags=re.M) data = json.loads(text.strip()) data["year"] = int(data["year"]) # "2024" → 2024
Regex strips the fences. A type cast fixes the numeric field stored as a string.
✓
Clean output
{ "city": "Geneva", "year": 2024 }
Parseable, typed correctly. No second model call needed.
03Where It Fits

Its place in the taxonomy.

L4
Home layer
Output Shape & Decoding sub-axis. Coercion acts on the output of a single model call. It is code running after decoding, not a second model call.
L4
Neighbor
Schema Enforcement prevents the problem before it occurs; Format Coercion cleans it up afterward. In practice both are used together: enforce a schema where possible, coerce edge cases that slip through.
L2
Cross-reference
If the fix requires another model call (asking the model to reformat its own output), that moves to L2 Verify or L5 if it triggers a retry loop. Pure code transformation stays in L4.
Filing rule: Deterministic code operating on a single call's output. No new model call, no second actor. L4 Output Shape & Decoding.
04When It Matters

Who needs this.

Any team integrating with third-party models where you cannot control the decoding parameters, or where the model occasionally wraps JSON in markdown, uses smart quotes instead of straight quotes, or returns numbers as strings. Format coercion is the defensive layer that makes the pipeline robust to minor model inconsistencies without adding latency or cost from a retry or a second call.
