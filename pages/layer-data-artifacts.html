Data & artifacts

The raw stuff everything is built from: text the model learned from, documents it looks things up in, number-lists that encode meaning, and the trained model file itself.

01The Idea

What is it?

Before any AI can answer a question, four things have to exist. First, training data: the enormous pile of text the model read to learn how language works. Second, documents: the specific files or web pages you give it to look things up in. Third, embeddings: every piece of text turned into a list of numbers so that similar ideas end up sitting close together in space. Fourth, weights: the actual trained model file, billions of numbers that encode everything it learned. Every other layer in this book sits on top of these four.

03A real example

How it fits in practice.

A company wants to let employees ask questions about internal policy documents.

Documents
200 PDF policy files.
The raw source of truth. Text is extracted and cleaned.
→
Embeddings
Each paragraph becomes a number-list and is stored in a vector database.
Enables fast "find the most similar chunk" search.
→
Weights
A pre-trained language model (e.g. GPT-4) reads the retrieved paragraphs and answers.
The model's knowledge comes from its training data; the documents supply the specifics.
