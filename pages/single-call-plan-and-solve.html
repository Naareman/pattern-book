Plan-and-Solve

Tell the model to make a plan first, then work through it. Separating planning from execution cuts careless errors.

01What It Is

Plan first, then solve.

Plan-and-Solve prompting requires the model to write a step-by-step plan first, then execute it, preventing it from jumping into calculation before it has oriented itself.

02An Example

A word problem solved in two phases.

Prompt structure for a word problem
PLAN
Instruction added to prompt
First, devise a plan to solve the problem. List the steps you will take.
SOLVE
Model output (abbreviated)
Plan: 1) Find total items. 2) Find rate per hour. 3) Multiply by hours. Step 1: 240 items total. Step 2: 240 / 8 hours = 30 items/hr. Step 3: 30 x 3 = 90 items.
03Where It Fits

How it relates to nearby ideas.

What it shapes
The "make a plan first" instruction is just text in your prompt. The model follows it inside one call, with no extra search or extra steps behind the scenes.
Compare to
Chain-of-Thought is the classic "think step by step" approach. Plan-and-Solve is different because the plan is written out first and kept separate from doing the work.
04When It Matters

When to reach for it.

  • The task has several steps in a row and the model keeps skipping some.
  • You see arithmetic or logic errors creeping in mid-answer.
  • Your tasks vary too much to write worked examples for, so a plan instruction is simpler.
