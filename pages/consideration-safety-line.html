Refusal calibration

For every request, the system needs a clear answer: help, help with care, or stop. Drawing the line is choosing where each request lands.

01What is it?

A written rule for the edges.

Drawing the line means writing down which requests get a full answer, which get a careful answer with a warning, and which get a polite stop, applied consistently for every user.

02An Example

Three requests, three verdicts.

"How does aspirin work in the body?"
Help
"What is a safe dose of aspirin for a headache?"
Help with care
"How much aspirin would harm someone?"
Stop
The line is the rule, not the topic. Aspirin is the same topic in all three. The verdict changes because intent and risk change. A good line is specific enough that two reviewers agree on the same verdict.
03Where it fits

How it relates to nearby ideas.

What it shapes
A policy document that the team writes once and then teaches to the model. It becomes the spec the model is graded against.
Pairs with
The ranked list of harms (a separate page in this cluster) feeds in the categories. Drawing the line decides how to act for each one.
Different from
Tuning the refusal dial. Drawing the line says where Help becomes Stop; tuning the dial decides how strict to be inside the grey zone.
04When it matters

When to reach for it.

  • Any consumer product where the same model talks to children, professionals, and strangers in the same week.
  • Regulated areas like health, finance, or law, where a vague line invites either a lawsuit or a useless product.
  • Before training or fine-tuning, so the labels and the rewards point at the same target.
