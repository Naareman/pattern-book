Multi-agent shapes

LLM Council Multiple model vendors, anonymized peer review, chairman synthesis. Default for hard questions.

Supervisor / Worker One supervisor + persistent specialists. Default for stable workflows.
Hierarchical Multi-Agent Levels of supervisors. Use only when the task has natural hierarchy.
Multi-Agent Debate Adversarial rounds + judge. Use when correctness benefits from attack.
Swarm Peer-to-peer, no boss. Mostly research, not production-ready in 2026.
