Retrieval and Q&A

The answer already exists somewhere. The AI finds it and hands it back.

01What is it?

Locate and return.

The output is content that lives in a known place: a document, a database, a help center, a chat history. The AI reads the question, finds the matching piece, and returns it.

02An Example

Question in, fact out.

Question
When does my order arrive?
→
Found in
Order record #4471
Answer: Tuesday, 3 June (from the shipping field). The AI located the row, read one field, and returned it.
03Where it fits

How it sits next to other shapes.

Sits next to
Extraction. Retrieval brings a chunk back as is. Extraction pulls structured fields out of that chunk.
Not the same as
Generation. Generation invents new text. Retrieval returns text that already existed and can be cited.
04When it matters

When to reach for it.

  • The right answer lives in a trusted source and you want to point at it.
  • Citations and source links are part of the user experience.
  • Made-up answers would be the worst possible failure (legal, medical, financial, support).
