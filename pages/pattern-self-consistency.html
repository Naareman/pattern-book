Pattern

Self-Consistency

Ask the same question several times, let each run reason its own way, then pick the answer that comes up most often. Random mistakes get outvoted.

01The Idea

What is it?

Self-Consistency asks the AI the same question several times and returns whichever answer came up the most.

02See It Work

Five runs, one vote.

Watch five runs of the same question appear. Each reasons differently and may land on a slightly different answer. Then see the vote resolve.

Question (sent 5 times, same model) A train travels 60 km in 45 minutes. What is its speed in km/h?
Vote tally
Majority answer

Run 3 took a wrong turn, but 4 out of 5 agreed. The majority vote corrects the outlier without any human checking.

Worth the extra cost?
