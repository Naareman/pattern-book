Stateful Memory

How an AI remembers what happened, what you prefer, and how it should behave, across this session and future ones.

Three kinds of memory: events that happened, facts about you, and routines it has learned.

Episodic memory

Specific things that happened: this chat, past sessions, everything the agent has done this run.

Conversation memory (this session) Memory of past conversations (per user) Task log (what the agent has done this run) Scheduled summarisation
see how →

Semantic memory

Distilled facts about a user: preferences, identity, and what they knew at any point in time.

Long-term user profile (per user) Time-aware knowledge graph (Graphiti / Zep style) Tiered memory store (Letta / MemGPT style) Cross-session identity and continuity (per user)
see how →

Procedural memory

How-to knowledge the agent carries: files it can read and write, skills it knows to trigger, and workflows it reuses.

Virtual filesystem / scratchpad (Deep Agents) Auto-invoked skill triggers Workflow templates remembered across sessions
