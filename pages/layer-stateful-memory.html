Stateful Memory

How an AI remembers things across turns and across sessions.

01The Idea

What is it?

An AI model has no built-in memory between conversations. Each request starts fresh. Stateful Memory is the layer that adds persistence: the system stores what was said, what the user prefers, or what happened in a past session, then writes that context back into the prompt (the text you send the AI) when it is needed. A token (a small piece the AI works in: roughly a word, or a slice of an image or sound) costs something, so memory systems have to be selective about what they keep, what they compress, and what they let go.

03Inside This Layer

All the categories in L3b.

Axis: how persistent knowledge accumulates and is recalled across sessions.
Conversation memory
The rolling window of recent turns, sometimes compressed into a summary, that keeps the current session coherent. Earlier turns stay in the prompt until the window fills; then the oldest ones are dropped or summarized.
Long-term user memory
Preferences and facts about you that persist across sessions: your name, your preferred language, topics you care about. The system writes these into future prompts so the AI does not ask again what it already knows.
Episodic memory
Recollection of specific past events: "last Tuesday we were debugging your login flow." Episodic memories are stored with enough detail that the AI can surface them when the current context makes them relevant.
Memory consolidation
The process of compressing or promoting memories over time. Short-term notes get merged into a summary; important facts get moved to long-term storage; redundant memories get merged so the store does not grow without bound.
Memory retrieval triggers
The rules or signals that decide when to surface a stored memory. A trigger might be a keyword, a topic match, or a similarity score that says "this moment is enough like a past moment to be worth remembering."
Memory eviction and forgetting
The deliberate removal of memories: old or low-value ones are evicted to make room, or deleted on user request. Forgetting is not a failure; it is how the system stays manageable and respects privacy.
Cross-session identity and continuity
Connecting who the user is across separate sessions so memory is correctly attributed. Without this, memory is anonymous and cannot be personalized. With it, the AI can greet you by name and pick up where you left off.
Filing rule: Persists across sessions and is tied to a user or conversation → Stateful Memory (L3b). Loaded fresh for one answer → Stateless Retrieval (L3a).
04Tradeoffs

What you gain and pay.

Stateful memory makes conversations feel natural and personal. The cost is real: every remembered turn and stored fact adds tokens to the prompt, which increases latency and cost. Longer memory also accumulates private information that must be managed carefully. Good systems consolidate aggressively and evict what is no longer useful.
