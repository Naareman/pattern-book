Example Ordering

Once you have chosen your few-shot examples, put them in the right sequence. Position within the prompt changes which patterns stick.

01What It Is

Sequence as a signal.

Example ordering is the deliberate sequencing of few-shot demonstrations so the most relevant example appears last, exploiting the model's recency bias to prime it immediately before it generates.

02An Example

Ordering by increasing relevance.

Few-shot prompt order (sentiment classification, query is a product review)
1
"The film was breathtaking." → Positive (movie review, broad coverage)
broad
2
"Arrived two days late." → Negative (e-commerce, closer domain)
closer
3
"Battery drains fast but build quality is great." → Mixed (product review, same domain)
most relevant
Next: your actual query. The model's last frame of reference before generating is the product review above. That recency effect improves classification accuracy on mixed-sentiment product text.
03Where It Fits

Where it fits.

Home
A way of writing your prompt. You set the order of the examples before sending, so it shapes the input to one call. It is not a separate call or tool.
Neighbor
Example Selection picks which examples to include. Example Ordering decides their sequence once picked. Both shape the prompt and usually go together.
In short: ordering the text in one prompt is a writing decision. It needs no second call, no special decoding, no tool, so it stays in one call to one model.
04When It Matters

When to reach for it.

  • You already use examples in your prompt and get inconsistent results without having tuned their order.
  • Especially for sorting tasks, where the model can lean toward the label of the last example it saw.
  • Quick test: compare random order against ordering by relevance. The gap is often bigger than expected.
