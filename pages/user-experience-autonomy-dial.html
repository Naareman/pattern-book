Autonomy levels & guardrails

One setting decides how far the AI is allowed to go on its own. The user can turn it up when they trust it, turn it down when they want to watch each step.

01What is it?

From suggest to act on its own.

An autonomy dial is a single visible setting that says how much the AI may do without asking. Low: it only suggests, you do the work. High: it acts on its own and tells you afterwards. Same AI, same tools, different leash. The user sees the level and can change it.

02An Example

Tap a level to see what changes.

An email assistant, four levels
Suggest

The AI offers ideas. You write and send everything yourself.

What the AI does

  • Reads the incoming email
  • Suggests three reply angles

What you do

  • Write the reply
  • Hit send
Visible and reversible. The level is always shown on screen and changeable in one tap. People only trust higher autonomy if they know they can pull it back instantly.
03Where It Fits

Where it sits.

Two halves
The runtime rules and guardrails behind the scenes (the orchestration side) and the dial the user sees and turns (the user interface side). This page is about the dial.
Pairs with
The pause before a big action and the path to a real person. Together they give the user a steering wheel, a brake, and an emergency exit.
Not the same as
Model choice or temperature. Those settings change how the AI thinks. The autonomy dial changes how far it is allowed to act.
04When It Matters

When to reach for it.

  • The same AI is used for both low-stakes and high-stakes tasks and a single fixed setting would feel wrong for one or the other.
  • Users vary in trust and skill: a power user wants the AI to run, a new user wants to approve each step.
  • You are rolling out a new feature and want a knob to ease people in instead of one big leap.
