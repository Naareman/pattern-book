Prompt Templates

A fixed prompt with labeled slots that your code fills at runtime. Write the instructions once, reuse them across every request.

01What It Is

Instructions that travel well.

A prompt template is a versioned string with placeholder slots that your application fills with dynamic values at request time, separating the craft of writing instructions from the mechanics of passing data.

02An Example

One template, many requests.

Template (stored in version control)
You are a code review assistant.
Review the following {{language}} code for bugs, style issues, and security problems.
Explain each issue in one sentence. Severity: critical / warning / info.

<code>
{{code_snippet}}
</code>

Context: this runs in {{environment}}.
Filled for one request
You are a code review assistant.
Review the following Python code for bugs, style issues, and security problems.
Explain each issue in one sentence. Severity: critical / warning / info.

<code>
def get_user(id): return db.query(f"SELECT * FROM users WHERE id={id}")
</code>

Context: this runs in a public-facing web API.
03Where It Fits

How it relates to nearby ideas.

What it shapes
The filled-in template is the text that goes into the model call. This pattern is about how you build that text from a reusable skeleton plus fresh values.
Then what
A template is a file you save and reuse. Keeping track of its versions over time is a separate job. This pattern is about how the template is built and filled in.
04When It Matters

When to reach for it.

  • You run the same kind of task over and over with different inputs: document Q&A, translation, code review, data extraction.
  • Your prompt wording is getting tangled up inside application code and is hard to test.
  • You want prompt writers and engineers to work in separate files with clear roles.
