Retrieval triggers

Holding a memory is not enough. Something has to look at what you just said and decide which old note (if any) belongs in the reply.

01What it is

Pick the right note for this moment.

A retrieval trigger is the rule that scans the memory store each time you send a message and pulls only the entries that match what you are asking about right now.

03Where it fits

How it sits next to nearby ideas.

Sits next to
Saving the memory in the first place. Saving puts a note in the drawer. The trigger is what reaches into the drawer and picks the right one for this moment.
How it picks
Common ways: meaning match (the topic looks similar), keyword overlap, recency, or importance scores. Many systems mix all four.
04When it matters

When to reach for it.

  • The memory store is too big to load everything every time.
  • The model brings up things you do not want it to (the wrong memory at the wrong moment).
  • The model forgets things you would expect it to remember (the right memory never gets pulled).
