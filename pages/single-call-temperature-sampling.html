Temperature & Sampling

Control how predictable or adventurous the model's word choices are, from a single number.

01What It Is

One dial, two extremes.

Temperature scales the token probability distribution before each pick: low values make the most likely token dominate, high values give rare words a real chance.

02An Example

Drag to see the effect.

temperature 0.2

Task

03Where It Fits

How it relates to nearby ideas.

What it shapes
It is a setting you pass with the call that controls how the model picks each word as it writes. One number, one call.
Compare to
Beam search also works as the answer is written, but it keeps several candidate sentences going at once. Logit biasing nudges specific words up or down before this same word-picking step.
04When It Matters

When to reach for it.

  • Predictable tasks (data extraction, classification, structured output): keep it near 0 so the model picks its top answer every time.
  • Creative tasks (copywriting, brainstorming, stories): raise it for fresh variation each run.
  • Getting this one number wrong is a top cause of either dull answers or shaky structured output.
