Extraction and classification

Pull structured fields out of messy text, or stick a label on each piece.

01What is it?

Turn prose into structure.

The AI reads unstructured text and returns structured data: named fields, lists of items, or category labels that the rest of your software can use directly.

02An Example

From a paragraph to fields and labels.

Input text
Hi, I'm Layla Hassan calling about invoice #A-2204. Total is $1,840, due 15 June. My email is layla@kemet.co.
→
Structured output
nameLayla Hassan
invoiceA-2204
amount$1,840
due2025-06-15
emaillayla@kemet.co
Each ticket gets one label
"App crashes when I open settings."Bug
"Can you add a dark mode?"Feature request
"How do I change my plan?"Question
"I want a refund."Billing
03Where it fits

How it sits next to other shapes.

Sits next to
Retrieval. Retrieval brings the right document. Extraction reads that document and pulls out the fields you need.
Pairs well with
Schema enforcement and constrained decoding: lock the output shape so the data is safe to hand to a database or downstream step.
04When it matters

When to reach for it.

  • Forms, invoices, receipts, contracts, or emails arrive as messy text and downstream software needs clean fields.
  • Incoming traffic has to be sorted into buckets: support categories, sentiment, priority, risk class.
  • The output is easy to grade against a key, so quality can be measured cheaply at scale.
