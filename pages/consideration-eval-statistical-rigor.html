Statistical rigor

Treat each eval score as a measurement with uncertainty. A small difference on a small test set is often noise, and pretending it is a real win wastes weeks.

01What It Is

A number with error bars.

Statistical rigor means treating every eval score as an estimate with uncertainty, not a fact, because a 2% gain on 50 cases is often noise while the same gain on 5,000 usually means a real change.

02An Example

Same gap, two different stories.

Two test runs comparing model A vs model B
A · 50 cases
78% ±10
B · 50 cases
80% ±10
A · 5,000 cases
78% ±1
B · 5,000 cases
80% ±1
60%70%80%90%
Top: the two ranges overlap heavily. The 2-point lead is inside the noise. Bottom: the same 2-point lead, but the ranges no longer overlap, so model B really is better.
03Where It Fits

How it relates to nearby ideas.

What it is
A way of reading any eval score. It says: never compare two numbers without knowing how noisy each one is.
Pairs with
A bigger and broader golden set, and reporting per-topic breakdowns so you can see where a real gap sits.
04When It Matters

When to reach for it.

  • Two prompts or two models look close: rigor tells you whether to ship the change or keep iterating.
  • Eval cases are expensive (human graders, long runs): you need to know if 100 cases is enough or if you need 1,000.
  • You report a number to a stakeholder: a confidence interval keeps the conversation honest.
